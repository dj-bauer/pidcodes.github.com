A cost-optimized open hardware DAC to control a laser projector via Ethernet. The design uses a STM32H7 micro controller with an analog front end from off-the-shelf components. Created as a bachelor thesis at the University of Bonn, it provides an open, low-cost reference with accurate sample timing and software-failure resilience. The hardware can run arbitrary servers / protocols and output stable continuous waveforms at 100 kpps. The bill of materials supports a retail price below EUR 100. The project currently runs the field-tested OpenIDN framework and added an adapter driver with low-level hardware offloading for the output stage.
